# Frontend — задачи по фазам

Владелец: агент фронта. Папка: `frontend/`. Контракт: `docs/CONTRACT.md`.
Отмечай выполненное `[x]`. Каждая фаза заканчивается зелёными `npm run typecheck`, `npm run lint`, `npm test`.

## Архитектура фронта

```
frontend/src/
├─ app/                 App.tsx, layout (панели с ресайзом), горячие клавиши
├─ shared/              types.gen.ts (генерируется), effects-registry.ts (импорт shared/effects.json), time.ts, ids.ts
├─ api/                 client.ts (fetch + ошибки), ws.ts (переподключение), mocks/ (MSW-хендлеры по shared/fixtures)
├─ store/               project.ts (Zustand+Immer), history.ts (undo/redo на патчах Immer), ui.ts (выделение, зум, плейхед),
│                       jobs.ts, assets.ts, selectors.ts
├─ model/               чистые функции без React: invariants.ts, ops/ (applyOps + раскрытие макро), timeRemap.ts,
│                       snapping.ts, markers.ts, cutToMarkers.ts, envelope.ts, keyframes.ts, easing.ts
├─ timeline/            Timeline.tsx (Canvas 2D), рендер слоёв, хит-тест, инструменты взаимодействия (drag/trim/box-select)
├─ playback/            clock.ts (мастер-часы по AudioContext.currentTime), videoPool.ts, audioEngine.ts
├─ render/              renderer.ts (WebGL2), compositor.ts, effects/*.glsl + *.ts, frameSource.ts
├─ export/              exporter.ts (WebCodecs + Mediabunny), audioMix.ts (OfflineAudioContext)
├─ panels/              MediaBin, Preview, Inspector, EffectsLibrary, AIPanel, CurveEditor, ExportDialog
└─ ai/                  opsPreview.ts (дифф для подсветки), AutoEditWizard.tsx
```

Правила:
- Вся логика изменения проекта — в `model/` (чистые функции, покрыты Vitest). React-компоненты только вызывают их.
- Любое изменение проекта идёт через `store.dispatch(ops)` или через `store.transact(fn)` → одна запись в истории.
- Таймлайн — один `<canvas>` с `devicePixelRatio`, перерисовка по `requestAnimationFrame` только при изменениях (dirty-флаг).
- Никаких прямых `fetch` из компонентов — только `api/`.

## Фаза 4 — Рендерер и эффекты

### 4.1 Рендерер (`render/`)
- [ ] WebGL2-контекст на canvas превью; ресайз с сохранением аспекта проекта.
- [ ] `frameSource`: в превью — текстура из `<video>` (`texImage2D` + `requestVideoFrameCallback`); в экспорте — `VideoFrame` из Mediabunny. Единый интерфейс `getFrame(clip, srcTime) → TextureSource`.
- [ ] Пайплайн кадра в момент `T`:
  1. для каждой видимой дорожки снизу вверх: для клипа под `T` — `src = timeRemap(T)`, кадр → transform (ключи) → эффекты клипа (по порядку) → смешение в аккумулятор по `blendMode`/`opacity`;
  2. fx-дорожка: её активные эффекты применяются к текущему аккумулятору;
  3. вывод на экран.
- [ ] Пинг-понг FBO, пул текстур, никакой аллокации в кадре.
- [ ] Каждый эффект — модуль `{ def: EffectDef, compile(gl), render(gl, input, output, params, intensity, localTime, rng) }`. `intensity` = envelope(t) × параметр «сила».
- [ ] Детерминированный шум: сид = hash(effect.id) + номер кадра, чтобы превью и экспорт совпадали.
- [ ] Счётчик fps в углу превью (dev).

### 4.2 UI эффектов
- [ ] Библиотека эффектов (панель с категориями и поиском, анимированные превью-иконки — опционально).
